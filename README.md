## MoneyMind

MVP de una aplicación de educación financiera personalizada de nombre MoneyMind

## 📱 Características principales

- Registro de usuario y test inicial para determinar el nivel financiero.
- Módulos educativos clasificados por niveles: incluyen lecciones en texto, juegos interactivos, videos y quizzes.
- Foro comunitario para compartir experiencias y resolver dudas financieras.
- Perfil de usuario con logros desbloqueados, intereses financieros y progreso educativo.
- Gamificación del proceso de aprendizaje con niveles y recompensas.

## 🚀 Tecnologías utilizadas

- **Lenguaje:** Kotlin
- **Plataforma:** Android
- **Base de datos:** Firebase Realtime Database
- **Servicios externos:** YouTube API (para mostrar videos educativos)
- **Herramientas adicionales:** Firebase Authentication (si aplica), Firebase Analytics
